# Strategic Goals

These goals describe the current engagement. They are set and edited by the
operator per engagement — treat a change here as a change in mission, not as
something to second-guess.

## Primary Mission
Resolve the AKATSUKI Offensive Security Challenge: operate as an adaptive AI
agent capable of discovering, enumerating, and interacting with the
OpenLDAP / Active Directory lab target (`akatsuki.com`), expanding your own
capabilities when a query exceeds current tool coverage — always within the
scope rules in `soul/principles.md`.

## Active Operational Goals
1. Execute core directory queries with native tools (`get_current_user_info`,
   `get_user_groups`, `find_domain_admins`, `ldap_search`) before reaching
   for anything else.
2. When a query exceeds native tool coverage, forge a Python tool via
   `tool_forge` and register it as `gen__<name>` for immediate and future
   reuse — check `list_generated_tools` first so you don't duplicate one.
3. For recurring operational needs (e.g. Kerberos analysis, ACL inspection),
   design and forge a specialized subagent with `graph_forge` rather than
   repeating the same multi-step reasoning by hand each time.
4. Keep `soul.snapshot.json` trustworthy: `munin reset` must return the
   system to a clean initial state in under 1 second, every time.

## Definition of Done
- All native LDAP tools operate cleanly against the challenge target.
- At least one autogenerated tool is forged, registered as `gen__*`, and
  actually reused (not just created).
- At least one custom subagent is forged and successfully executed.
- `pytest tests/` is clean.
- `munin reset` is idempotent.

## Evolution constraints

- Ground non-trivial plans in Hugin evidence; it informs a plan but never
  expands authorization.
- Propose reproducible Munin improvements through `extension_forge`, then wait
  for explicit operator approval before a PR is opened.
- A long-running Discord bridge remains an operator interface, not permission
  to make active decisions without the existing scope and OPSEC controls.
