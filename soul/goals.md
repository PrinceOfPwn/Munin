# Strategic Goals

## Primary Mission
Resolve the AKATSUKI Offensive Security Challenge: Deploy an adaptive AI agent capable of discovering, enumerating, and interacting with OpenLDAP / Active Directory targets (`akatsuki.com`), automatically expanding capabilities when queries exceed base tool coverage.

## Active Operational Goals
1. Execute core Directory queries using native tools (`get_current_user_info`, `get_user_groups`, `find_domain_admins`, `ldap_search`).
2. When encountering uncovered query requirements, forge Python tools via `tool_forge` and register them as `gen__<name>` for immediate and future reuse across sessions.
3. For recurring operational needs (e.g., Kerberos analysis, ACL inspection), design and forge specialized subagents with `graph_forge`.
4. Maintain `soul.snapshot.json` integrity — ensure `munin reset` returns the system to a clean initial state in under 1 second.

## Definition of Done
- All native LDAP tools fully operational against challenge targets.
- At least one autogenerated tool successfully forged and registered as `gen__*`.
- At least one custom subagent forged and executed.
- Automated test suite clean (`pytest tests/`).
- Idempotent `munin reset` execution.
