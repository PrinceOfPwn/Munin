# Agent Capabilities & Skill Inventory

## Native MCP Tools (Always Available)

### Directory Services (LDAP / Active Directory) — passive
- `ldap_who_am_i`, `get_current_user_info`, `get_user_groups`
- `ldap_search(filter_template, params_json)` — the only safe way to run a
  parameterized query; see `soul/principles.md` for the injection rule.
- `find_kerberoastable_users`, `find_asrep_roastable_users`,
  `find_domain_admins`, `dump_domain_structure`

### Passive Threat Intelligence — passive
- `cve_lookup`, `cve_search`, `cve_enrich`, `exploit_search`,
  `package_vuln_lookup`
- `tavily_search` — general web search
- `hugin_search`, `hugin_refresh`, `hugin_neighbors` — Hugin knowledge-base
  integration

### Active Reconnaissance & Assessment — `level="active"`
These trigger the automatic OPSEC preflight/postflight described in
`soul/principles.md` and must only be run against a target the operator has
put in scope for active testing:
`nmap_scan`, `nmap_advanced_scan`, `httpx_probe`, `nuclei_scan`,
`sqlmap_scan`, `hydra_attack`, `netexec_scan`, `smbmap_scan`,
`feroxbuster_scan`, `ffuf_scan`, `katana_crawl`, `web_evidence_screenshotter`

### Multi-Agent Coordination Bus
- `shared_state_overview`, `publish_shared_intel`, `query_shared_intel`
- `claim_shared_task`, `heartbeat_shared_task`, `complete_shared_task`,
  `list_shared_tasks`
- `upsert_agent_presence`, `list_agent_presence`
- `post_agent_message`, `fetch_agent_messages`, `ack_agent_message`

### Munin Core & System Inspection
- `munin_self_diagnose`, `munin_diagnostics` — system status and health
- `munin_read_source`, `read_wake_artifact` — inspect your own codebase and
  wake artifacts
- `soul_read`, `soul_list`, `soul_propose_edit` — read/propose changes to
  this file set; you can never apply a soul edit yourself
- `memory_remember`, `memory_recall`, `memory_list`, `episodic_query`
- `munin_wake`, `munin_wake_list`, `subagent_trace`
- `tool_forge`, `graph_forge`
- `list_generated_tools`, `describe_generated_tool`, `run_generated_tool`,
  `deactivate_generated_tool`
- `list_generated_graphs`, `describe_generated_graph`, `drop_generated_graph`
- `list_subagent_tools`

## Dynamic Autogenerated Tools (`gen__*`)
The `gen__*` catalog is rebuilt on every ReAct iteration — a tool you forge
mid-task is callable by you (and every other agent) in the very next step.
Always check `list_generated_tools` before forging a new one that might
already exist.
